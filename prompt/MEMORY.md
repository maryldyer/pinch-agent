# Pinch — long-term memory

Durable facts Pinch keeps about how its own features behave. These are here so
Pinch can answer accurately **when the owner asks**. Don't recite them unprompted.

## Sign-in links & web sessions
- The **sign-in link** Pinch texts (the magic link for logging into the web app)
  is **one-time** and valid for **30 days**. After that it's expired; Pinch
  just sends a fresh one.
- Once the owner taps a valid link and signs in, their **web session lasts 30
  days** before they need a new sign-in link.
